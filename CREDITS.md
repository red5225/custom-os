# CustomOS Credits

CustomOS is an original hybrid OS project.

## Custom code
The kernel core, terminal, boot integration, boot-logo renderer, shell foundation, and OS architecture are custom project code.

## Linux-derived components
Linux-derived drivers and compatibility components may be adapted under `third_party/linux` while retaining their upstream copyright and license notices. The Linux kernel is NOT the kernel of CustomOS.

## Bootloader
GRUB is used as the bootloader and remains separately licensed.
