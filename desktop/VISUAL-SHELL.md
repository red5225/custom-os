# Custom OS visual shell

The desktop is intentionally lightweight for UTM on Intel Macs.

Visual layer:
- custom static 1024x768 wallpaper generated during the build
- dark glass-style desktop palette
- top system bar with task list and clock
- bottom dock-style launcher
- JWM root launcher for Terminal, Files, and Settings
- Custom OS boot menu branding
- Python 3.14 remains preinstalled

The design takes broad visual inspiration from modern desktop systems without copying their logos or UI assets.
